# Konsep Al Afghani Juice

**Konsep Al Afghani Juice** adalah website pemesanan minuman berbasis web yang digunakan oleh pembeli saat datang langsung ke kedai. Pembeli dapat melihat menu, memilih minuman, memasukkan pesanan ke keranjang, dan melakukan pembayaran melalui Cash atau QRIS. Pesanan akan masuk ke dashboard kasir untuk dikonfirmasi dan diproses hingga selesai.

Sistem ini dilengkapi fitur pengelolaan produk, harga, stok, dan transaksi menggunakan database MySQL, serta menerapkan **Stored Procedure, Function, Trigger**, dan transaksi **COMMIT** serta **ROLLBACK**.

## Teknologi yang Digunakan

- Laravel (PHP)
- HTML
- CSS
- JavaScript
- MySQL
